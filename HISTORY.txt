V3.0.0  (Based on V2.0.0)      			                  04/01/2024
================================================================================
- Changed the autoval/validate/waterlevel.py to include:
    - Use searvey package instead of csdllib package to download CO-OPS 
      observational data.
    - Added functionality to download, process, and compare the IOC water level 
      values with the model output.
    - Added functionality to run the code for both Pacific and Atlantic domains
      by passing the "pacific" variable into the *.ini file.
    - Added functionality to save the country of a station for the new report
      file.
    - Added functionality to use different datums for CO-OPS observationl data 
      by passing the "VDatum" variable into the *.ini file.
    - Added functionality to plot the nowcast period in addition to the forecast
      period.
    - Added functionality to show the corrected bias on time series.
- Changed the autoval/tests/*.ini to include the "Pacific", "VDatum", "Nowcast",
  "NowcastPeriod", "NowcastPeriodineachfile", and "DynamicBiasCorrection" variables
   required for the new version. 
- Changed autoval/report/html.py to list the stations based on their location
  and observational data source in alphabetical order.
- Changed autoval/report/field.py to plot the coastline and spatial maps 
  independently of the "csdllib" package.
- Changed autoval/report/skill.py to plot the averaged skill maps independently 
  of the "csdllib" package
- Changed the autoval/plot/waterlevel.py to plot the nowcast period in addition 
  to the forecast period.
- Changed the autoval/plot/waterlevel.py to show the corrected bias on
  time series.
- Added new .ini domain files for the Pacific domain.
- Moved tests, cfg.domains, and cfg.storm folders out of the autoval code 
  directory.
- Updated README.md to include more information for users.
- Added four tests for new users.
- Added requirements.txt file listing the required libraries.
- Removed "csdllib" dependency from setup.py as it is not functioning properly 
  and causing errors.
- Updated package version in setup.cfg.
- Updated package version in autoval/version.py.

Updated V3.0.0  (Based on Updated V3.0.0)                   08/18/2026
================================================================================
- Changed autoval/validate/waterlevel.py to include:
    - Removed dependency on searvey.uhslc for IOC station metadata lookup.
      The searvey.uhslc module hardcodes the global_hourly_fast ERDDAP dataset
      which contains only ~11 stations, causing all other UHSLC stations to be
      silently skipped.
    - Added _query_uhslc_erddap() helper that queries the UHSLC ERDDAP REST API
      directly, trying global_hourly_fast first and falling back to
      global_hourly_rqds (research-quality dataset with ~533 stations).
    - Added _decode_uhslc_country() helper to fix double-encoded UTF-8 country
      names (e.g. Reunion, Cote d'Ivoire, Curacao) and strip stray quotes
      that resulted from incorrect CSV splitting of comma-containing country
      names (e.g. "Micronesia, Federated States of").
    - Replaced manual CSV split(',') with pandas.read_csv() in ERDDAP response
      parsing to correctly handle country names that contain commas.
    - Added _get_ioc_stations_cached() helper that fetches and caches the full
      IOC station list from the IOC sea level monitoring website.
    - Added coordinate-based nearest-IOC fallback in getUHSLC_StationInfo():
      for UHSLC stations absent from both ERDDAP datasets, the nearest IOC
      station within 1.5 degrees is used to obtain the IOC code. This resolves
      ~31 additional stations (e.g. UH914 Meulaboh, UH908 Port Blair, UH818
      Smogen, UH541 Bamfield, UH340 Kaohsiung) that were previously listed as
      "Other Stations without Observation" despite having IOC data.
    - Added module-level cache (_UHSLC_SSC_CACHE, _IOC_STATIONS_CACHE) to avoid
      redundant HTTP calls during parallel station processing.
    - Propagated model lon/lat through getIOC_Country() and getIOCData() to
      enable the coordinate-based fallback lookup.
